# GameV11
## Overview
This folder contains the source code and assets for a JavaScript/HTML platformer game called "Collapse." The game challenges players to control a character, avoid falling obstacles, and survive through multiple levels. It features custom character animations, sound effects, and progressively difficult levels.

## Files
- `menu.html`: Main menu of the game with options to start the game or view credits.
- `instruction.html`: Instructions page explaining how to play the game.
- `Level1.html`, `Level2.html`, `Level3.html`: HTML files for the three levels of the game.
- `Game.css`, `Game2.css`, `Game3.css`: Stylesheets for each level.
- `Game.js`, `Game2.js`, `Game3.js`: JavaScript files implementing game logic for each level.
- `GameOver.html`, `GameOver2.html`, `GameOver3.html`: Game over screens for each level.
- `Congrats.html`: Congratulatory screen displayed upon completing the game.
- `credits.html`: Credits page listing contributors to the game.
- `theme.mp3`, `hit.wav`, `DeathSoundEffect.mp3`: Background music and sound effects.
- `Images/`: Folder containing all game assets, including backgrounds, buttons, and character animations.

## Features
- Three challenging levels with unique backgrounds and increasing difficulty.
- Custom animations for the player character, including idle and running states.
- Falling obstacles that players must avoid to survive.
- Lives system with visual indicators for remaining lives.
- Timer-based gameplay for each level.
- Background music and sound effects for an immersive experience.
- Game over and congratulatory screens for player feedback.
- Credits and instructions pages for additional context.

## Gameplay Instructions
1. Use the arrow keys (`←` and `→`) or `A` and `D` keys to move the character left and right.
2. Avoid falling obstacles to prevent losing lives.
3. Survive until the timer reaches zero to progress to the next level.
4. Complete all levels to win the game.

## Compilation & Usage
To play the game:
1. Open `menu.html` in a web browser to start the game.
2. Navigate through the menu to view instructions or start the game.
3. Progress through the levels by surviving the falling obstacles.

To modify the game:
- Edit the HTML, CSS, or JavaScript files to customize levels, styles, or game logic.
- Replace assets in the `Images/` folder to update visuals.
